Privacy Policy

Last updated: September 2026

This Privacy Policy explains how PikoTots Timeline Studio accesses, uses, stores, and protects information when using YouTube API Services.

PikoTots Timeline Studio is a private creator tool used by the owner of the PikoTots YouTube channel.

Use of YouTube API Services

PikoTots Timeline Studio uses YouTube API Services to connect to an authorized YouTube account and assist with channel and video management.

The application may use the YouTube Data API to:

  • Identify the authenticated YouTube channel.
  • Upload approved videos.
  • Manage video metadata and privacy settings.
  • Retrieve authorized channel or video information.

Google Account Authorization

Access to YouTube is provided through Google OAuth 2.0. PikoTots Timeline Studio does not collect or store the user's Google password.

Google provides authorization tokens after the user grants permission. These tokens may be stored locally on the user's computer so the application can continue to access the authorized YouTube account.

Information Stored

PikoTots Timeline Studio may store limited information locally, including:

  • OAuth authorization credentials or tokens.
  • YouTube channel identifiers.
  • Uploaded video identifiers and URLs.
  • Video titles, descriptions, tags, and upload status.
  • Locally generated scripts, videos, captions, and metadata.

This information is used only to operate the creator workflow and manage the authorized PikoTots YouTube channel.

Sharing of Information

PikoTots Timeline Studio does not sell personal information or YouTube API data.

Data is not shared with third parties except where necessary to provide functionality through Google and YouTube API Services or where required by law.

Data Retention

Application data is generally stored locally on the user's computer and may be deleted by the user at any time.

OAuth access can also be revoked at any time through the user's Google Account security settings.

Security

Children's Privacy

PikoTots Timeline Studio is a creator-side software tool and is not intended for direct use by children. It does not knowingly collect personal information from children.

Changes to This Policy

This Privacy Policy may be updated as the application develops or as legal, Google, or YouTube API requirements change.
